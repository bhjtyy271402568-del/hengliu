# V4 两块板的 PCB 分区、器件摆放和设计要点（草案，2026-10-26）

对象：10-26 版恒流源板（40 A）+ 辅助电源板，上下叠装。器件和网络按 `10.26/ProPrj_可调恒流源_2026-10-26.epro2` 核对。
坐标、尺寸都是**建议值**；散热数值是**推断**（散热器、风量、导热垫是假设），要样机热测试确认。
图解（1:1 俯视分区、侧视叠装）：https://claude.ai/artifact/53pET3PzV9mZvzqD4hK34L

## 0. 散热改成紧凑方案（取代 `V4_散热与叠装设计.md` 第 3 节的大散热器）

用户要“精致、好看”，HS01（150 × 120 × 48 mm）+ 92 mm 风扇整机约 250 × 140 × 150 mm，太大。改法：

| 项 | 原方案 | 紧凑方案 |
|---|---|---|
| 散热器 | HS01 150 × 120 × 48 mm，露在外面 | 约 **90 × 60 × 30 mm**（底 5 + 鳍 25），藏在机壳里，只垫在开关区下面 |
| 风扇 | 92 mm 吹两层 | **60 × 60 × 15 mm** 装在出风端，整个机壳当风道（进风格栅在另一端） |
| U2（150 W 模块） | WHR3 带散热片伸进夹层 | **WFR3 铝底座版**（62 × 56 × 14.6 mm，手册）倒扣贴上盖，机壳当散热器 |
| 机壳 | 无 | 铝型材壳，约 **195 × 120 × 80 mm**（含 15 mm 风扇，体积约为原来的 1/3） |

为什么能缩：散热器热阻主要看“风速 × 面积”。小散热器配风道，风全部从鳍片缝里过，约 0.7–0.9 K/W（推断）；
原来的大散热器配 92 mm 风扇约 0.35 K/W。差的这部分用温度余量换。

结温估算（机箱内 40 °C；结到散热器热阻沿用 `V4_散热与叠装设计.md` 第 4 节：SuperSO8 5.9 K/W、D²PAK 3.8 K/W）：

| 方案 | 进散热器 | 散热器 | 上管结温 | 输入 P 管 | 风扇坏了 |
|---|---|---|---|---|---|
| 原方案 HS01 + 92 mm | 36 W | 约 52 °C | 约 82 °C | 约 72 °C | 约 105 °C，可撑 |
| 紧凑 + 60 mm | 36 W | 约 69–76 °C | 约 99–106 °C | 约 89–96 °C | 撑不住，靠 NTC 降额 |
| 紧凑 + 输入改 N 管热插拔 | 约 26 W | 约 61–66 °C | 约 91–96 °C | N 管约 70 °C | 同上 |

公式：T散热器 = T环境 + 空气温升（约 4 K）+ P × Rθ；T结 = T散热器 + P管 × Rθ结-散热器。

结论（推断）：
- 紧凑方案上管约 100 °C，低于 125 °C 设计上限，可用，但余量比原方案少约 20 °C。
- **最有效的“缩散热器”办法是少发热**：输入两只 SUM110P08 + Q4 共约 13 W，占进散热器热量的 1/3。
  换成 N 管热插拔（辅助板已在用 LM5069；100 V、约 1.5 mΩ 的 TOLL 封装 N 管两只并联约 1.4 W，Q4 两只并联约 1.2 W）能省约 10 W。
  这是原理图改动，用户和 Codex 决定（器件参数待规格书）。
- 风扇是 2 线常转、没有测速。风扇坏了只能靠 R67 NTC 降额（40 A 时约 90 °C 起降）。建议改 3 线风扇，测速进 MCU（原理图改动，待定）。
- 如果系统里泵浦用的水冷板能借用，恒流板直接压在冷板上：散热器约 35 °C、上管约 65 °C，不要风扇，最小最静（要确认冷板）。

## 1. 叠装和机壳

侧视（风从左往右，出风端装风扇）：

```
 ┌──────────────────── 上盖（铝） ────────────────────┐
 │        ▓ U2 WFR3 铝底座 + 导热垫，螺钉固定在上盖     │  ← 辅助板顶面
 │  ══════════ 辅助板 1.6 mm（尼龙柱）══════════════   │
 │  →  夹层 ≥ 40 mm，L8 高 34.2 mm 是最高件（10-27 更正）  →        │
 │  ══════════ 恒流板 1.6 mm ══════════════════      ▐风扇
 │       ▓▓▓ 导热垫 0.5 mm（绝缘）▓▓▓                 ▐60mm
 │  →    ║║║║ 散热器 90×60×30 ║║║║   →               ▐
 └──────────────────── 底板 ──────────────────────────┘
   进风格栅                                    出风
```

高度：底板 2 + 散热器 30 + 垫 0.5 + 恒流板 1.6 + 夹层 27 + 辅助板 1.6 + U2 14.6 + 垫 0.5 + 上盖 2 ≈ 80 mm。

- 两块板同一外形 **170 × 110 mm**，四角 M3 孔对齐（距边 5 mm），圆角 R3。原 20 A 板是 120 × 95 mm。
- 两块板之间**没有电连接**：辅助板从电池线分叉经自己的 J1 取电；外部使能来自控制卡，接恒流板的 U3。所以不用板对板连接器。
- 面板：左端 = 电池输入（CN3 + J1）+ 进风；右端 = 激光输出 CN14 + 风扇；前面（长边）= 振镜 / 控制卡端子、外部使能、指示灯、调试口。
  功率从左到右一条直线，大电流不绕弯。也可以全部接口放一端（功率路径走 U 形，回路长一些），由用户定。
- 辅助板上 U2 是最高件（14.6 mm）；板上 Ø10 电解要选高度 ≤ 14 mm 的，否则顶到上盖；或在上盖内做 3 mm 凸台只压 U2。

## 2. 恒流板分区（俯视，x 向右 0–170，y 从前 0 到后 110）

```
 y=110 ┌────────┬──────┬────────────┬──────────┬───────┐
       │ A 输入 │B 母线│ C 开关区   │ D 电感   │ E 输出│
  CN3→ │ 保护   │ 电容 │ (热回路)   │  L8      │ R56   │→CN14
       │Q1 Q2 Q4│C6-C8 │上管 Q5-Q7  │ 36×36    │6×Ø10  │
       │D2 C20  │R42   │SW / 下管   │          │D12    │
 y=52  ├────────┴──┬───┴──F LT3763─┴──┬─I 检测─┤       │
       │ H 辅助电源 │ G MCU          │INA310  │       │
       │ U5 12 V   │ U2 X1 U7 U8    │        │  CN6  │
       │ U6 5 V    │                 │        │  风扇 │
 y=0   └──────────┴── J 接口与指示：CN4 K1 K2 灯 U4 U3 ───┘
         [散热器投影：x 20–112，y 50–110]
```

| 区 | 位置 | 器件 | 要点 |
|---|---|---|---|
| A 输入保护 | 左后 x 0–48 | CN3、D2、C20 + R1、Q4、Q1、Q2、Q3 / U1 / C1 / C5 / R7 | D2 和 C20 + R1 贴着 CN3；Q4 靠 CN3 负极；Q1、Q2 在散热器上 |
| B 母线电容 | x 48–70 | C6 + R4、C7 + R215、C8 + R216、C9–C19、R42 | 电解在 R42 之前；R42 竖放，进 LT_VIN |
| C 开关区 | x 70–108，散热器正上方 | LT_VIN 陶瓷 29 只（C63–C77、C106–C119）、上管 Q5–Q7、下管 Q8–Q10、R71 / C94、R72 / C95、D11 | 全板最关键，见第 4 节 |
| D 电感 | x 108–146 | L8 | 插件 169 g，点胶；正下方 L2 不挖空也不走信号 |
| E 输出 | 右侧 x 146–170 | R56、C84 / C97–C101（6 × Ø10）、C85 / C86 / C102–C105、D12、CN14 | D12 贴 CN14；FB 和 VOUT 取样在电容组处取 |
| F LT3763 | 中前 x 70–118 | U9、C91–C93、C79 / D10、R73 / C96、RT / SS / FB / CTRL 外围 | U9 的 TG / BG / SW / BOOST 脚朝向开关区 |
| I 电流检测 | x 118–146 | U201 INA310、R201–R204、Q202 | 靠近 R56，开尔文线短 |
| G MCU | x 26–70 | U2、X1、U7、U8、去耦 | 远离 SW 和 L8 |
| H 辅助电源 | 左前 x 0–26 | U5 + L3（12 V）、U6 + L6（5 V） | 靠近 DCBUS 入口；L3 / L6 不放在 MCU 晶振旁 |
| J 接口与指示 | 前沿 y 0–14 | CN4、K1、K2、L1 / L2 / L4 / L5 / L7、U4 TLP2761、U3 外部使能、D4–D8 | 指示灯一排对齐，配导光柱；U4 下开隔离槽 |

- PGND / GND 单点：U9 裸焊盘旁一处桥接铜（已定）。
- R67 NTC：放在下管前面 GND 铜上，离下管约 2–3 mm（热耦合、电气不接 PGND）。
- 散热器压紧螺钉 6 个：x 22 / 66 / 110，y 56 / 108；螺钉孔接 PGND（散热器接 PGND 的建议，见 `V4_散热与叠装设计.md` 第 6 节）。

## 3. 辅助板分区（同外形，叠在上面）

```
 y=110 ┌──────────────── BAT 侧（下面正对恒流板功率区）────────────────┐
  J1→  │ F1  Q1  D1  R2/U1  Q2   C5 C6 C7 C9（输入电容）   Q3/Q4/D3  │
 y≈58  │ ─ ─ ─ ─ 隔离带 ≥ 2.5 mm，所有层无铜；Y 电容焊盘跨在带上 ─ ─ ─ │
       │   ┌─U2 WFR3─┐                 ┌─U3─┐                        │
       │   │输入脚在后│                 │    │                        │
       │   │输出脚在前│                 │    │                        │
 y=0   └─ U2 输出滤波 ── J2 J3（振镜）── U3 输出滤波 ── J4（控制卡）──┘
                         AUX 侧（下面正对恒流板控制区）
```

| 区 | 器件 | 要点 |
|---|---|---|
| BAT 侧（后半） | J1、F1、Q1（+ R1 / D2 / C1）、D1、U1 LM5069 + R2–R11 / C2–C4、Q2、C5–C7 / C9、C8 / C10、Q3 / Q4 / D3 | 底层整块 BAT_GND 铺铜，正好盖在恒流板开关区上方当屏蔽 |
| 隔离带 | y 约 56–59 | 所有层无铜 ≥ 2.5 mm（功能绝缘，推断）；U2 / U3 跨带摆放，输入脚在 BAT 侧、输出脚在 AUX 侧 |
| AUX 侧（前半） | L1–L3、C11–C18、R12–R14、D4 / D5、两只 SMDJ17A、J2 / J3 / J4 | AUX_GND 汇接点放在端子旁；振镜回流和控制卡回流分别回汇接点 |

- U2 用 WFR3，铝底座朝上，经导热垫用螺钉固定在上盖；U3 约 4 W，靠夹层气流和铜皮。
- D4 / D5 现在是 STPS10L60D（TO-220 立式），只做反向钳位、平时不过电流，可换贴片同类肖特基，板面更平整（换型核对浪涌能力）。
- 安装孔不接任何网络，用尼龙柱，隔离不被铜柱短路。

## 4. 恒流板 PCB 要点（40 A）

1. **层叠**：4 层、外层 2 oz（内层 1–2 oz）。L1 功率和器件；L2 整块地（功率区下是 PGND，控制区下是 GND，两块只在单点相连）；
   L3 功率平面复制（LT_VIN、SW、VOUT）和少量信号；L4 底层散热铜岛 + 大电流并联。
2. **大电流宽度**（IPC-2221，温升 20 °C，计算）：40 A 在外层 2 oz 单层约要 16 mm 宽；顶底两层各 20 A 时每层约 6 mm，按 ≥ 8 mm 留余量，层间多打过孔。
   内层同样电流要宽得多（约 2.6 倍），不要靠内层走 40 A。每个 0.3 mm 过孔按约 1 A 算，换层处至少 40–60 个。
3. **热回路最小**：LT_VIN 陶瓷 → 上管漏极 → SW → 下管源极 → PGND → 陶瓷负端。陶瓷离上管漏极、下管源极 ≤ 3 mm，L2 的 PGND 紧贴在下面作回流。
   回路电感 5 nH 时 40 A / 50 ns 尖峰约 4 V，20 nH 时约 16 V（计算）。
4. **SW 铜皮小而短**：只需从下管漏极连到 L8 引脚，不要大面积铺。底层 SW 散热岛每只约 8 × 8 mm（对散热器约 17 pF，比 15 × 15 mm 的约 60 pF 小，计算）。
5. **栅极驱动**：TG 和 SW、BG 和 PGND 成对并行走线（≤ 20 mm），3 只管从驱动端星形分出、长度相等；每只管的栅极电阻贴在管子栅极；
   12k 下拉贴管子。BG 回流回 U9 的 PGND 脚，不走大电流地。
6. **采样开尔文**：R56、R42 从焊盘内侧引出采样线，成对走到芯片；10 Ω + 33 nF 滤波贴 U9 引脚放。
   INA310 从 R56 焊盘单独再引一对线，不和 LT3763 共用。采样线不经过 L8、SW 下方。
7. **散热过孔**：每只 SuperSO8 ≥ 60 个、D²PAK ≥ 80 个，0.3 mm；焊盘内过孔做树脂塞孔电镀填平，防止吸锡。
   底层散热岛按网络分开（LT_VIN 一块、SW 每只一块、DCBUS、GND_BAT），间距 ≥ 1 mm，阻焊开窗；导热垫必须绝缘。
8. **散热器接地**：压紧螺钉孔接 PGND，就近在下管源极附近。
9. **控制区**：MCU、晶振、模拟（AVCC、VREF、NTC、DAC）在前半，离 SW 和 L8 ≥ 15 mm；DAC → CTRL1、FB 线在 GND 区内走，不跨 PGND。
10. **外部信号隔离**：U4 TLP2761 下面开槽，LED 侧（外部地）铜皮和板上地隔开。
11. **机械**：L8 点胶，靠近安装孔；LCB50 靠板边，螺钉固定；散热器螺钉均匀压在器件区四周。
12. **测试点**：SW、VOUT、ISMON、CTRL1、INTVCC、PWM 留测试点，放板边好夹探头；SW 测试点用短接地弹簧的位置（示波器探头地线要短）。

## 5. 辅助板 PCB 要点

1. **隔离带**：所有层无铜 ≥ 2.5 mm；模块下方按金升阳推荐版图禁止走线；Y 电容焊盘（URF 1 nF、URB 2.2 nF）跨隔离带、贴着模块放。
2. **输入路径**：J1 → F1 → Q1 → D1 → R2 → Q2 → 模块，5–7 A，2 oz 外层约 3 mm 宽够用；LM5069 采样线从 R2 焊盘内侧开尔文引出。
3. **D1 TVS** 贴 J1 后、Q2 之前；输入电容贴模块输入脚。
4. **输出**：每路 L、C、阻尼电阻、TVS 按“模块 → 滤波 → TVS → 端子”顺序排；TVS 和反向钳位二极管贴端子。
5. **地**：BAT_GND 在后半整块铺铜（屏蔽恒流板功率区）；AUX_GND 在前半，振镜和控制卡回流分开到汇接点。
6. **安装**：孔不接网络；U2 上盖螺钉孔按 WFR3 手册尺寸开。
