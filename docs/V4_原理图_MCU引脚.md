# V4 原理图 · 第 5 步：MCU 引脚分配和外围读回

2026-10-24。接第 2–4 步：把第 2、3 步留下的 MCU 信号落到具体引脚，补上输出电压、输入电压、温度、风扇的读回和控制，列出固件要求。
位号用 5xx 段。MCU 沿用 V1 的 STM32G431RBT6（LQFP64），暂记 U2。
标注：G431 手册 = DS12589 Rev 1；手册 = LT3763 规格书 Rev C；计算；推断；V1 = `ProPrj_恒流源_2026-09-29.epro2` 新页和 `hengliu.ioc`。

## 1. 分配原则

1. **安全相关的输出脚，复位时（引脚高阻）必须自己落到安全状态**：靠外部上 / 下拉，不靠固件。所以这类信号不用 PA13–PA15、PB3、PB4（JTAG 脚复位时带内部上 / 下拉）。
2. 要快的模拟量（输出电流、输出电压）放 ADC 快速通道（IN1–IN5）。
3. 要中断的输入，EXTI 线号不能重复（PA8 和 PB8 共用 EXTI8）。
4. V1 已经验证过的脚尽量不动：PA4（DAC）、PA8（SHOOT）、PB12（FAULT）、PB14 / PB15（ISMON / IVINMON）、PB10 / PB11（串口）、PC9（按钮）、PC13（运行灯）。

## 4. 核算

### 4.1 风扇：MCU 复位时全速（计算 + 推断）

- 4 线风扇的 PWM 脚：悬空 = 全速（风扇内部上拉，Intel 4 线风扇规范，推断待风扇规格书确认）。
- 所以用 Q501 开漏去拉低：MCU 输出高 → Q501 导通 → PWM 脚被拉低 → 转得慢；MCU 复位 → R509 把栅极拉低 → Q501 断开 → 风扇全速。
- 固件里 TIM 输出极性取反即可。PB6 复位时没有内部上拉，所以不选 PB4（JTAG 的 NJTRST 复位时带上拉，会让风扇变慢）。

### 4.2 NTC：比例测量（计算，100k B3950 按标称）

- 上拉接 3V3A，也就是 ADC 的参考电压，所以 3V3A 的误差在比值里抵消，温度读数不受 LDO 精度影响。

  | 温度 | 25 °C | 60 °C | 80 °C | 85 °C | 100 °C | 125 °C |
  |---|---|---|---|---|---|---|
  | ADC 电压 | 3.00 V | 2.35 V | 1.85 V | 1.72 V | 1.36 V | 0.87 V |
  | 灵敏度 | 15 码/°C | 30 码/°C | 32 码/°C | 31 码/°C | 28 码/°C | 20 码/°C |

- 灵敏度最高的区间正好在 60–100 °C，也就是要做调速和降额判断的地方。

### 4.3 输出电压、输入电压读回（计算）

- VOUT：100k / 10k 0.1%，比值误差 ≤ ±0.2%，30 V 时 ±0.06 V。输出端负极到 GND 汇接点之间的 PGND 压降（40 A × 约 0.5 mΩ ≈ 20 mV，推断）也会算进读数，约 0.07%。
- VIN：150k / 10k 1%，32 V 判断点误差约 ±0.6 V，只用于欠压降额判断，够用。
- 三组输出分压（FB 限压、33 V 过压、VOUT 读回）各自从输出接口单独取点（第 3 步布局要求 4）。

### 4.4 参考电压

- VREF+ 接 VDDA（3V3A，LP5907），和 V1 一样；第 2、3 步的 DAC 范围都按这个算。
- 固件每次采样同时读内部 VREFINT（出厂校准值存在芯片里），算出实际 VDDA，再换算所有通道。
- 没有用芯片内部的 VREFBUF（2.9 V，±0.14%）：用它的话 DAC 只保证到 2.7 V，CTRL1 进不了 1.5 V 钳位，第 2 步的 R204 和第 3 步的限压范围都要重算（G431 手册 Table 71 + 计算）。

### 4.5 限压 DAC 写 0 的情况（计算）

- 第 3 步按 DAC 最低 0.2 V 算上限 30.5 V。如果固件误写 0 码、DAC 输出接近 0 V：
  限压 = 1.206 × (1 + 100 / 5.9) + 1.206 × 100 / 11.3 ≈ **32.3 V**，碰到 33 V 过压的下限（约 32.3 V）。
- 处理：固件把限压 DAC 码夹在 0.2 V 对应值以上。MCU 复位时 DAC 是高阻，限压回到 21.7 V，不受影响。

## 5. 固件要求（写固件时照这个做）

| 项目 | 要求 |
|---|---|
| 上电 | 所有输出先保持复位默认值；先发一次 FAULT_CLR 脉冲清 INA310 锁存（此时 EN_MCU 低）；读 PG、VIN；外部信号若已经有效，**先等它撤销再触发** |
| 启动 | PG 高、锁存已清、VIN ≥ 32 V → 设 CTRL1 DAC 和限压 DAC → EN_OFF 拉低 → **等 ≥ 20 ms**（INTVCC 电容充电，第 6 步）→ EN_MCU 拉高 → LT3763 软启动约 42 ms → 外环接管 |
| 停止 | EN_MCU 立刻拉低；外部信号无效超过 T_短停（1–5 ms，按控制卡用法定）再把 EN_OFF 拉高复位芯片 |
| 外部信号 | SHOOT_N 双边沿中断 + 1 ms 轮询（V1 写法）；停止优先 |
| 过流锁存 | CMPOUT_MON 上升沿 → EN_MCU 低、记故障、红灯；只有用户命令才清除：EN_MCU 保持低 → FAULT_CLR 脉冲 → 再走完整启动 |
| 硬件被拦 | EN_MCU 高、外部有效、PG 高，但 PWM_MON 低 → 说明过压比较器或锁存在拦 → 停机报原因 |
| LT3763 FAULT | 中断记录；结合 VOUT、IOUT 判断开路 / 短路（FB 判据在低限压时不可靠，第 3 步） |
| 读回 | ADC + DMA 连续采样；每轮读 VREFINT 校正；IOUT 按每块板的出厂校准（增益、零点）换算 |
| 交叉核对 | INA310 读数和 ISMON 相差超过约 15% 持续 10 ms → 检测通路故障，停机（ISMON 精度只有 ±10%，阈值待样机定） |
| 设定限制 | 电流 ≤ 40 A；功率 VOUT × IOUT ≤ 960 W，超了降电流；限压 ≤ 30 V 且 ≤ VIN − 2 V；限压 DAC 码不低于 0.2 V 对应值 |
| 输入 | VIN < 32 V 降额或停机；VIN 读数和 IVINMON 一起估输入功率 |
| 温度和风扇 | NTC_MOS 定风扇转速（约 40 °C 起升速、70 °C 全速）；约 80 °C 起降电流、约 95 °C 停机（数值待散热测试定；第 3 步硬件降额约 85 °C 起在后面兜底） |
| 风扇故障 | 指令转速 > 30% 而测速低于约 300 rpm 超过 2 s → 降到 20 A，温度继续升就停机（数值待定） |
| 看门狗 | 沿用 V1：IWDG 约 200 ms、CSS → NMI → 关断 |
| 调试按钮 | 只能在外部使能有效、联锁闭合时起作用（硬件与门决定，第 3 步待用户确认） |

## 6. 布局要求

1. PA4、PA5 两路 DAC 线和 PA0、PA1 两路 ADC 线远离 SW 和风扇线；分压电阻放 MCU 一侧，长线走在分压之前（高压侧电流小，抗干扰）。
2. NTC501 和第 3 步的 NTC301 贴同一只最热的上管；NTC502 放电感和输出电容之间。两只 NTC 的回线直接回 GND，不和功率地共用。
3. 风扇线（12 V、PWM、TACH）从电源角落直接出板，不穿过模拟区。
