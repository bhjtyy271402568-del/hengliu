## 2. 整板保护：出了事谁管

| 出的事 | 谁发现 | 做什么 | 多快 | 怎么恢复 |
|---|---|---|---|---|
| 输入接反 | Q703 / Q704 不导通 | 整板不通电 | 立即 | 接对即可 |
| 输入尖峰 | D701 | 钳在约 77 V 以下 | 立即 | 自动 |
| 输入持续过压（误接 48 V） | LM5069 OVLO | 关断 Q701 / Q702 | 微秒级（推断） | 降回约 42 V 以下自动恢复（推断） |
| 输入欠压 | LM5069（23 V）、LT3763 EN（24.3 V）、固件（32 V） | 依次停机 | — | 自动 / 固件 |
| 插电冲击 | LM5069 功率限制 | 约 11 ms 慢慢充母线 | — | — |
| 板内短路（输入侧） | LM5069 断路器 / 限流 + 计时 | 关断并**锁存** | > 105 A 立即；限流 22 ms | 断电重上 |
| 上面都失效 | F701 50 A | 熔断 | 秒级 | 换保险丝 |
| 激光支路输入过大 | LT3763 IVIN（37–46 A） | 自动压低输出电流 | 环路速度 | 自动 |
| 输出电流设大了 | CTRL1 钳位 | 硬件封顶约 45.7 A（含公差） | — | — |
| 检测通路坏（SENSE 断、电容短路等） | INA310 比较器（典型 53 A） | 拉低 PWM 并**锁存** | 约 3 µs | MCU 命令清除 |
| 电感电流尖峰 | LT3763 逐周期（85 mV ≈ 71 A） | 当周期关上管 | 每周期 | 自动 |
| 输出过压 | LT3763 限压环；33 V 比较器；固件读 VOUT | 限压 / 拉低 PWM / 停机锁定 | 连续 / 约 16 µs / 毫秒 | 自动 / 固件 |
| 负载开路 | 限压环接管；固件看 VOUT 到限压且 IOUT ≈ 0 | 停机 + 放电 | 0.1 ms / 约 0.1 s | 用户重新启动 |
| 负载短路 | 恒流本身允许；固件看 VOUT 过低报警；D901 钳住反向振荡 | 报警 / 停机 | 毫秒 | 用户 |
| 过温 | 固件 NTC（约 80 °C 降、95 °C 停）；硬件 CTRL2（约 85 °C 起降） | 降额 / 停机 | 秒级 | 冷却后用户重启 |
| 风扇停转 | 固件测速 | 降到 20 A，温度还升就停 | 2 s | 自动 / 用户 |
| 控制侧电源异常 | TPS3808（5 V、3.3 V 模拟） | PG 低 → 与门关 | 立即 | 电源恢复后 20 ms |
| MCU 死机 | IWDG（约 200 ms） | 复位；所有输出脚落到安全态：EN_MCU 低、LT3763 关、风扇全速、放电开 | ≤ 200 ms | 自动重启，但不自动出光 |
| 联锁断开 / 外部信号撤销 | 光耦 LED 灭 → 与门 | 硬件直接关 PWM | 立即 | 闭合 / 重新触发 |
| 振镜一路短路 | TPS54560B 限流 | 该路限流 | 每周期 | 自动 |
| 控制卡短路 | F802 自恢复保险丝 | 断开 | 秒级 | 自动 |

### 规格书（本环境打不开 TI / ADI / 立创，要用户下载放进 `数据手册/`）

LM5069、TPS54560B、INA310A、TPS3808、TLV3011、URF4824QB-200W、CPCF3535-6R8M、HoLRS3920、EEHZS1H221P、
输入 / 输出陶瓷电容和 47 µF 的直流偏压曲线、Q701 / Q702 候选管的 SOA 曲线。

### 要选型号（Claude 列候选，用户查货）

Q701 / Q702（看 SOA）、D803、D901、L802 / L803、F701 座、F801、F802、M5 螺柱端子、R901 / R902（脉冲）、C201（33 nF ±5% C0G）、
2.5 V 栅压有规格的小 NMOS（Q201 / Q301 / Q302 / Q310 / Q501 / Q801 / Q902 同料）。

### 样机要量的

R115 寄生电感和 45 A 时 INA310 OUT 波形；PWM 拉低到停止开关的时间；最高输出电压下的电流环（有无一大一小交替）；
电流阶跃、恒流 / 限压切换、轻载 / 开路；长停后直接用 PWM 重开的过冲；母线电解纹波电流；
−15 V 带载能力和振镜回灌；放电时间；各器件热稳定温升（按大纲第 9 节）。
