# 输入级缓启动仿真（10.25 版）

用来定 C1、C5、R7（复核文件 `docs/V4_原理图复核_2026-10-25.md` 第 8.4 节）。纯 Python，不装任何库：

```
python3 -I sweep.py      # 约 1 分钟，输出和 结果.txt 相同
```

- `model.py`：电路方程（后向欧拉 + 牛顿迭代）。节点 VT（P 管源极）、V20（C20）、VA（U1 / R3 / R5 交点）、VB、VC（Q3 基极、集电极）、VG（P 管栅极）、VO（母线）。
- `sweep.py`：三组算例——插电误导通、缓启动结温和慢过压切断、直接插到过高电压。
- `结果.txt`：上次运行的输出。

## 假设（都是推断，不是手册保证）
| 项目 | 取值 | 来源 |
|---|---|---|
| 电源 | 理想电压源 + 50 mΩ，1 µs 内升到 42 V；**不含线缆电感** | 假设 |
| C2/C3 | 20 µF | 估计的有效值 |
| Q1∥Q2 | 平方律，K = 40 A/V²，阈值 1.0 / 2.5 V，Cgs 21.7 nF、Cgd 1.4 nF（两只合计） | SUM110P08 手册阈值 1–3 V；电容由 Ciss / Crss 典型值折算 |
| Q3 | Ebers-Moll，β = 100 | 假设 |
| U1 | 47 V 起导通，动态电阻 10 Ω | BZT52-B47 标称；小电流稳压值手册没给 |
| D1 | 12 V | BZT52C12 标称 |
| 母线 | 1.013 mF，负载 2 kΩ（激光未开） | 原理图电容合计 |
| 结温 | 功率曲线与 SUM110P08 单脉冲 Zth(j-c)（手册第 5 页读图，4 阶 Foster 拟合）卷积，× RthJC 最大 0.4 °C/W；壳温另加 | 手册读图 |

## 没算进去的
- 线缆电感引起的振铃（另见复核文件 8.2 节的手算）。
- 两只 P 管不均流：结温按“一只承担全部”算，是最坏情况，不是模型算出来的分配。
- 线性区局部热点（Spirito 效应）；手册 SOA 图看起来是按热阻画的恒功率线，没有证明线性区可靠性。
- C5、C1 的偏压和温度损失：要用实际有效容量代入 `base()` 重算。
