# 原理图版本登记

会话开始时，钩子运行 `python3 -I tools/epro_snapshot.py --status`，按文件指纹（SHA-256 前 12 位）对照这张表，
提示没登记的原理图文件（.epro2 / .epro / .enet）。同名文件被覆盖修改后指纹会变，也会被提示。

收到新版本时：

1. `python3 -I tools/epro_snapshot.py --diff 上一版.epro2 新版.epro2 [--old-board 板名] [--board 板名]`，
   看器件增删、改值和连接变化。连接按**原理图**的导线和引脚坐标计算（PCB 常常还没更新），
   脚本会提示 PCB 是否和原理图同步。用户指明了板名就用 `--board`；
2. 对照《项目记忆》核对关键值，把变化和疑点告诉用户；
3. 在下表加一行，更新项目记忆，提交推送。

脚本只能解析 .epro2（嘉立创 EDA 专业版新格式）。一个工程里可能有多块板（每块 = 原理图 + PCB），脚本默认取最近修改的那块。
按原理图算连线的方法已用 09-29 版验证：和已同步的 PCB 逐个焊盘对比，582 个全部一致。
注意：位号不可靠。用户会复制、挪用器件（例如 10-15 版把输入保护的 R7/R9/C8 挪到控制部分），按位号对比会把改名误报成改值，要以连线为准。
