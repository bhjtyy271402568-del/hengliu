# 2026-10-31 对话记录

## 辅助板：LM5069 + 放行电路怎么摆
- 问：LM5069 和放行电路后面直接接隔离模块对吧？每个元件放置要注意什么，怎么方便走线？
- 结论：链路确认（J1 → D1 → Q1 防反接 → R2 → Q2 / LM5069 → AUX_IN → U2 / U3），放行电路在一次侧。
  两层板底层整块 BAT_GND，顶层信号线不能横穿功率铜；10-27 版有 3 处必须跨（PGD 跨 R2 通路、两根 CTRL 跨 AUX_IN 母线）。
  建议：D1 紧贴 J1；D2 / C1 跨在 Q1 栅源脚之间；R2 / U1 / C2 保持 TI 式排列；放行电路挪到 Q2 右边、U3 下方，PGD 沿板边过去，
  CTRL 从模块输入脚右侧上去；开尔文从焊盘内侧边引出；小信号地汇到 U1 5 脚再一孔下地；功率铜 ≥ 5 mm（1 oz）。
