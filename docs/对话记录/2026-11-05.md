## 两个参考设计
- 问：用户上传 ARM + FPGA 开发板工程（STM32H7 + Tang 25K）和 GitHub pewpew-laserboard，让 Claude 学习。
- 结论：两个都是激光打标“控制卡”一侧的设计，对应我们的 DLC2-V2。PewPew 的激光使能与门、输出脚下拉和我们 V4 的原则一致；ARM + FPGA 的分工（FPGA 管 XY2-100 和激光门控、MCU 管文件）适合以后自做控制卡。
  ARM + FPGA 板查出 USB-A 上下拉冲突、主机口 5 V 无限流、32.768 kHz 负载电容可能偏小。
