# 辅助电源板前端布局规划（防反接 + LM5069 + 放行）

日期：2026-10-31。依据：10-27 版辅助板摆放（工程指纹 `c183273c7a5e`，PCB fac41427，坐标 y 向上），
LM5069 手册 SNVS452G 第 11 节（布局），复核文件 `docs/原理图与PCB复核_2026-10-27.md`。
图：`docs/仿真/布线演算/辅助板前端布局规划_20261031.png`（脚本 `aux_front_plan.py`）。

## 1. 链路（确认）

J1（XT30）→ D1 TVS → Q1 P 管防反接（R1 / D2 / C1）→ R2 8 mΩ → Q2（LM5069 U1 控制）→ AUX_IN 母线
→ C9（U3 输入）、C5–C7（U2 输入）→ U2 URF（+15 V）/ U3 URB（−15 V）。
放行：U1 PGD → R9 → Q3 → R10 → Q4 → D3 → 两只模块的 CTRL（参考模块的 −Vin = BAT_GND）。
整个前端和放行电路都在一次侧（BAT_GND），隔离由模块本身完成。

## 2. 核心思路：两层板上，信号线不跨功率铜

底层整块铺 BAT_GND，作为大电流的回路（去路在顶层、回路紧贴在它正下方，环路电感最小，手册要求“去路和回路平行且靠近”）。
所以顶层的信号线不能横穿功率铜，否则只能在底层地上挖缝跳过去。

10-27 版有 3 处必须跨（推断，按焊盘位置画路径）：
- U1 在功率路径（Q1 → R2 → Q2）和板边之间，PGD 要往上到放行电路，必须横穿 BAT_PROT / R2；
- AUX_IN 母线从 U3 第 3 脚沿模块输入脚左侧上到 C5–C7、U2 第 1 脚，把两只 CTRL 脚和左边的放行电路隔开，两根 CTRL 线都要跨母线。

## 3. 建议摆放

| 器件 | 放哪 | 理由 |
|---|---|---|
| J1 | 不动（左边中部，机械定） | |
| D1 TVS | 竖放紧贴 J1 右侧，两脚分别对 J1 的 + 和地 | 浪涌电流的环路越小，钳位电压越低；现在离 J1 约 12 mm |
| Q1 | 不动；漏极散热焊盘和 J1+ 用整块铜连起来 | 这块铜既是输入通路，也是 Q1 的散热铜 |
| D2、C1 | 竖放在 Q1 栅极脚和源极脚之间（两脚相距 5 mm，正好跨上） | 插电瞬间靠 C1 把栅源压住（10-25 仿真），连线越短越有效；现在离脚 6–10 mm |
| R1 | Q1 栅极脚下方，另一端打地孔 | 100 kΩ，电流很小，可稍远 |
| R2、U1、C2 | 保持现在的 TI 式排列：R2 在上，U1 在下，1、2 脚正对 R2 | 手册要求检流电阻靠近 LM5069 并用开尔文接法 |
| C2（VIN 旁路） | 贴 R2 输入焊盘（现在已经是） | 手册：短路关断瞬间输入 dv/dt 很大，电容放在 VIN 脚、走线又长时形成 LC，VIN–SENSE 会被拉开，所以电容靠近检流电阻 |
| R3–R6（UVLO / OVLO 分压） | U1 第 3、4 脚左侧 | 高阻节点要短 |
| C4（TIMER）、R7（PWR） | U1 第 6、7 脚正下方 | 同上 |
| Q2 | 不动（散热焊盘接 R2，栅 / 源脚朝右） | |
| C3 | Q2 源极旁 | |
| 放行电路 Q3、Q4、D3、R8–R11 | 挪到 Q2 右边、U3 下方（约 x 48–57、y 3–18） | PGD 从板边走过去不跨功率铜；R8、Q3 发射极就近接 Q2 源极的 AUX_IN |
| CTRL_N、CTRL_P | 从放行电路往上，走模块输入脚右侧（模块下方，一次侧）到 U3 第 1 脚、U2 第 2 脚 | 母线在输入脚左侧，CTRL 在右侧，互不交叉；离隔离带保持 ≥ 7 mm |
| C9、C5–C7、C8、C10 | 不动（输入脚左侧，母线经过它们） | |

## 4. 走线要点

1. 开尔文：SENSE、VIN 从 R2 两个焊盘**内侧边**（靠电阻体）引出，成对走到 1、2 脚，不接铺铜（恒流板 M1 的教训）。
   1 oz 铜 0.49 mΩ/□，取点往电流里偏 1 mm（5 mm 宽线）约 0.1 mΩ，是 8 mΩ 的 1.2%（计算）。
2. 小信号地：R4、R6、R7、C4 的地先在顶层汇到 U1 第 5 脚，再用一个孔下到 BAT_GND（手册：不要经大电流地互连）。
3. GATE / OUT 成对走：GATE 进栅极焊盘；OUT 从栅极焊盘下方绕到外侧再接源极，不用交叉。
   PGD 走最外面，贴板边经 C4 / R7 和 Q2 散热焊盘下方出去（PGD 要拉低约 6.6 V 才会让 Q3 导通，是最抗干扰的一根，适合走长线，计算）。
4. 线宽（1 oz，IPC-2221 外层，温升 10 °C，计算）：正常 4.7–5.2 A（140 W，27–30 V），限流 6.0–7.8 A 只持续到计时结束 → 功率铜 ≥ 5 mm（7 A 约 4.4 mm）；
   母线分到 U2 约 3.4 A、U3 约 1.8 A，分支 ≥ 3 mm。
5. 发热（计算，RDS(on) 热态按 × 1.6 推断）：Q1 5 A 时约 0.45 W，漏极铜 ≥ 4 cm²；Q2 稳态约 0.1 W，主要是启动时的 SOA（待核）；R2 约 0.2 W。
6. 底层：BAT_GND 整块，只允许 < 5 mm 的短跳线，且顺着电流方向；不要在功率路径正下方挖横缝。
7. 隔离：一次侧铜（含 CTRL 线）都在隔离带左边；叠装孔 3.5 mm 禁铜；U2 的 Ø3.5 安装孔位置补上后，CTRL 线要绕开。

## 5. 仍待定（不影响按上表摆放）

- PGD 在振镜峰值时关模块的问题（10-26）；如果改成锁存或 MCU 放行，放行电路位置不变。
- Q2 SOA（约 90 ms、约 47 W）、+15 V 容性负载 ≤ 2000 µF、控制卡电流。
- 铜厚 1 oz 还是 2 oz（2 oz 线宽约减半）。
