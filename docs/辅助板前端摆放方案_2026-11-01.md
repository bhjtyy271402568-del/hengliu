# 辅助板前端 + 放行电路摆放方案

日期：2026-11-01。基于 10-27 版辅助板（指纹 `c183273c7a5e`，PCB fac41427，2 层 1 oz），坐标 y 向上（和嘉立创一致），单位 mm。
图：`docs/仿真/布线演算/辅助板前端摆放_20261101.png`（全位号放大图 `辅助板前端摆放_位号_20261101.png`）；脚本：`aux_place_plan.py`（坐标 + 重叠 / 间距 / 禁布检查）、`aux_place_fig.py`（出图）。
脚本检查结果（计算）：挪动的 20 个件和全板其他件没有重叠；异网焊盘间距 ≥ 0.25 mm；没有进安装孔禁布区；都在 x ≤ 60 的一次侧。

## 1. 总体

- 功率路径沿板子下边一条线：J1 → Q1（防反接）→ BAT_PROT 横条 → R2 → Q2 散热焊盘 → Q2 源极 → AUX_IN 斜上到 U3 第 3 脚，
  再沿模块输入脚**左侧**上到 C9、C5–C7 和 U2 第 1 脚。
- U1 在功率路径外侧（靠板边）。这里没有大电流回流经过，地是安静的，所以 R4、R6、R7、C4 的地各打一个孔下到底层地也可以。
- 放行电路放在 Q2 右边、U3 下方（x 48–59，y 3–18）。PGD 从板边下方过去，不跨功率铜；
  两根 CTRL 从放行电路往上，走模块输入脚**右侧**（模块下面、一次侧），和左侧的母线不交叉。
- 一次侧铜到 x 60 为止；二次侧最近的铜（J4）在 x 69.9 以外。这条分界是示意，要和 Codex 定的铺铜边界对一下。

## 3. 走线要点

1. **BAT_PROT 横条**：Q1 源极脚 → 右到 R2 输入焊盘，高约 4.5 mm（1 oz、10 °C 温升约 7 A，IPC-2221，计算）。横条下沿离 Q1 栅极焊盘、D2 / C1 下端 ≥ 0.5 mm。
2. **Q1 栅极**：栅极脚 → D2、C1 下端一条短铜；R1 在背面，用一个过孔接。
3. **R3 / R5 的上端**从 R2 输入焊盘左下角引一根细线取 BAT_PROT。这根线只有约 0.7 mA（36 / 101k + 36 / 106k，计算），所以可以细。
4. **开尔文**：VIN 从 R2 输入焊盘内侧（右边缘）几乎直线下到第 2 脚；SENSE 从输出焊盘内侧（左边缘）斜下到第 1 脚。两根都不碰铺铜。
5. **3、4、5 脚出线**（只能往上出，0.5 mm 间距）：
   - 5 脚（地）往上 0.2 mm 就左拐到过孔，高度约 15.5；
   - 4 脚 OVLO 在 16.1 高度往左钻到 R3 下面，接 R5 下端；
   - 3 脚 UVLO 在 17.0 高度接 R3 下端。
   - 往左拐的线，越靠右的脚要拐得越高，否则会交叉。线宽 0.2 mm，间距按 DRC。
6. **下排出线**：6、7 脚就近到 C4、R7。8、9、10 脚往下到板边附近，三根平行线向右，从 Q2 散热焊盘下方走过：
   - PGD 高度 3.6，一直到放行电路的 R9；
   - OUT 高度 4.4，从栅极焊盘外侧绕上去接源极，不和 GATE 交叉；
   - GATE 高度 5.2，从散热焊盘和引脚之间（封装体下面）上到栅极焊盘。
7. **漏极铜**：R2 输出焊盘正下方就是 Q2 散热焊盘上沿，用一块约 7.5 × 6 mm 的铜连起来。AUX_IN 铜和它的间距 ≥ 0.5 mm。
8. **放行电路**：R8 上端 = Q3 发射极 = AUX_IN，就近从 Q2 源极焊盘右端取。Q4 发射极、R11 下端各打一个地孔，要靠近模块的 −Vin（CTRL 以 −Vin 为参考）。
9. **CTRL**：CTRL_N 在 x 约 57.4 往上，到 y 41.6 左拐接 U3 第 1 脚；CTRL_P 在 x 约 58.6 往上，到 y 71.5 左拐接 U2 第 2 脚。U2 的两个 M3 安装孔在 1 脚外侧和 4 脚外侧的对角，不挡这两根线。
10. **底层**整块铺 BAT_GND。背面只有 R1、R4、R6 三个小件，加上原有的 C3、C8、C10，地平面不被切断。

## 4. 还要在 EDA 里确认的

- 功率铜的形状以图为准，宽度和间距要以 DRC 为准；AUX_IN 从源极焊盘到 U3 第 3 脚这段最窄处要 ≥ 4.4 mm。
- 一次 / 二次侧铺铜边界和 Codex 的隔离要求对一下（图上画的 60–68 mm 是示意）。
- 不影响摆放、但还没定的：PGD 在振镜峰值时关模块；Q2 安全工作区；放行链能否简化成 PGD 直接经 D3 接 CTRL。如果改成直接接，删掉 R8–R11、Q3、Q4，D3 留原位。
